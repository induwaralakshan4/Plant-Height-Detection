### 📌 About the Project

Plant Growth & Automatic Height Detection is a Computer Vision project developed using Python and OpenCV to automatically detect a plant from images and estimate its height.

Images of the same plant were captured across multiple dates. The system processes these images to estimate the plant's height and observe its growth over time.

The main purpose of this project is to demonstrate how Computer Vision and Image Processing can be applied to a real-world problem such as automated plant growth monitoring.

### 📐 Plant Height Detection

The system uses image processing techniques to identify the plant and determine its visible height within the image.

Depending on the image setup and reference information, the detected pixel measurements can be converted into an estimated physical height.

Plant Image
     │
     ├── Detect Plant
     │
     ├── Find Top Point
     │
     ├── Find Bottom / Reference Point
     │
     └── Calculate Height

«Note: Accurate real-world height measurement depends on factors such as camera position, image scale, perspective, and the availability of a suitable reference or calibration method.»

### ⚙️ Installation

1. Clone the Repository

git clone https://github.com/YOUR-USERNAME/Plant-Growth-Detection.git

2. Navigate to the Project

cd Plant-Growth-Detection

3. Install Dependencies

pip install -r requirements.txt

If a "requirements.txt" file is not available:

pip install opencv-python

---

### ▶️ Running the Project

Run the main Python script:

python plant_height_detection.py

Make sure the required input images are available in the appropriate project directory.
